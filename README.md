# Group V2 — Calculadora de costos

Aplicación Next.js para cálculo de acrílico 3 mm por ⅛ de lámina con precios Vexcel de referencia (09/11/2026).

## Desarrollo

`npm install && npm run dev`

## Estado

Primera versión de interfaz y cálculo. **Aún no incluye autenticación ni persistencia**: no publicar sin configurar protección de acceso. Los precios son datos iniciales y se deben validar ante cambios de proveedor.
